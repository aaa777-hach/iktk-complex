# Project Plan — план проекта ИКТК

**Проект:** Интегрированный конструкторско-технологический комплекс (ИКТК)  
**Кодовое имя:** `iktk-complex`  
**Версия ТЗ:** `final_TZ.md` (ред. 3)  
**Версия документа:** 1.0  
**Статус:** утверждено

---

## 1. Общие сведения

**Название проекта:** Интегрированный конструкторско-технологический комплекс с программой-оркестратором («дирижёром»).

**Заказчик:** предприятие машиностроительной отрасли.

**Цель проекта:** разработать и внедрить комплекс автоматизированного проектирования методов и средств создания продукции, обеспечивающий сквозную технологическую подготовку производства (ТПП) с оркестрацией профильных модулей, анализом сборочных единиц, подбором оборудования и формированием рекомендаций при дефиците.

**Ключевые результаты (SMART):**
- Сокращение времени ТПП — не менее чем на 30 %.
- Снижение количества ошибок и переделок — не менее чем на 40 %.
- Повышение загрузки оборудования — не менее чем на 15 %.
- Срок выхода MVP — 6–8 месяцев с начала разработки.
- Срок выхода Релиза 1 — +4–6 месяцев после MVP.

---

## 2. Область работ (Scope)

### 2.1. Входит в проект

**MVP (6–8 месяцев):**
- Оркестратор («дирижёр») с конечным автоматом.
- Ядро, API Gateway, аутентификация.
- Модули: литьё, объёмная штамповка, механообработка (включая ЧПУ), нормирование.
- Интеграции с CAD: Siemens, Dassault, T-FLEX, КОМПАС.
- Веб-клиент (React + TypeScript) и Electron-оболочка.
- Граф ТП, страница проекта, реестр оборудования (базовый).
- Инфраструктура: PostgreSQL, RabbitMQ, MinIO, Kubernetes, GitLab CI.
- Версионность, аудит, откат.
- Документация, тесты (unit, integration, e2e, load).

**Релиз 1 (+4–6 месяцев):**
- Ввод имеющегося оборудования предприятия (полный реестр).
- Анализ сборочных единиц и BOM.
- Проектирование ТП сборки (assembly-process-service).
- Gap-анализ и рекомендации (recommendation-service).
- Каталог внешнего оборудования, аутсорс.
- UI: BOM-дерево, дефицит и рекомендации, реестр оборудования (расширенный).

**Релиз 2:**
- Внешние интеграции (заказчики, подрядчики).
- A/B-тесты технологических решений.
- Библиотека оснастки и материалов.
- Шифрование бэкапов, mTLS, подпись образов.

**Релиз 3:**
- Предиктивная аналитика.
- Интеграция с MES/ERP.
- Распределённые производства.

### 2.2. Не входит в проект

- Разработка собственных CAD-систем (только интеграция).
- Разработка MES/ERP.
- Аппаратное обеспечение, станки, оснастка.
- Обучение персонала заказчика сверх предусмотренного.
