## 1. Назначение

Документ описывает систему мониторинга, логирования и алертинга ИКТК. Используется для:

- обеспечения наблюдаемости всех сервисов комплекса;
- своевременного выявления проблем;
- разбора инцидентов;
- анализа производительности и планирования мощностей;
- отчётности по SLA/SLO.

**Стек мониторинга:**
- **Prometheus** — сбор метрик.
- **Grafana** — визуализация и дашборды.
- **Loki** (или ELK) — централизованный сбор логов.
- **Alertmanager** — маршрутизация алертов.
- **Spring Boot Actuator / Micrometer** — метрики сервисов.
- **postgres_exporter** — метрики PostgreSQL.
- **MinIO Prometheus** — метрики MinIO.
- **RabbitMQ Prometheus plugin** — метрики очередей.
