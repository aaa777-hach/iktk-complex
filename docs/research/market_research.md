## 1. Назначение

Документ описывает результаты анализа рынка систем автоматизации технологической подготовки производства (ТПП), конкурентов, аналогов и рыночных трендов. Используется для:

- обоснования функциональных требований к ИКТК;
- выбора приоритетных направлений развития;
- оценки конкурентных преимуществ;
- формирования ценностного предложения;
- стратегического планирования (см. `product_roadmap.md`).

## 2. Обзор рынка

### 2.1. Объём и динамика

| Показатель | Значение | Источник (ориентир) |
|---|---|---|
| Мировой рынок PLM/CAPP | ~50 млрд $ (2024) | Gartner, MarketsandMarkets |
| Прогноз роста | CAGR 8–10 % до 2030 | — |
| Российский рынок PLM/CAPP | ~25–30 млрд ₽ (2024) | Экспертные оценки |
| Прогноз роста РФ | CAGR 12–15 % | — |
| Доля импортозамещения в РФ | 30–40 % (2024) | — |

### 2.2. Драйверы рынка

1. **Импортозамещение:** уход западных вендоров ускорил переход на отечественные решения.
2. **Цифровизация производства:** переход к «Индустрии 4.0», цифровым двойникам.
3. **Сокращение сроков ТПП:** конкуренция требует быстрого запуска новых изделий.
4. **Интеграция CAD/CAM/CAPP:** разрозненные системы тормозят процессы.
5. **Дефицит кадров:** автоматизация компенсирует нехватку инженеров.
6. **Требования ОПК:** сквозная прослеживаемость, безопасность, изолированные контуры.

### 2.3. Барьеры рынка

1. **Высокая стоимость внедрения** PLM/CAPP-систем.
2. **Сложность интеграции** с существующим парком ПО.
3. **Сопротивление пользователей** при переходе.
4. **Длительные сроки внедрения** (6–24 месяца).
5. **Зависимость от вендора** (vendor lock-in).
6. **Недостаток стандартов** обмена данными.

## 4. Конкурентные преимущества ИКТК

### 4.1. Уникальные особенности

1. **Оркестратор («дирижёр»)** — единая программа, управляющая последовательностью ТПП. Аналоги не имеют полноценной оркестрации.
2. **Точки контроля** — смешанный режим (автоматически + ручное подтверждение).
3. **Gap-анализ оборудования** — автоматическое выявление дефицита и рекомендации.
4. **Аутсорс-опции** — встроенные варианты передачи операций.
5. **Сквозной аудит** — все решения фиксируются в `audit_log` и `decision_log`.
6. **Версионность по умолчанию** — снапшоты сущностей, откат.
7. **Импортозамещение** — ядро отечественное, интеграции — любые.
8. **Гибридная архитектура** — микросервисы + тяжёлые модули.
9. **Открытые API** — интеграция с любыми CAD/CAM.

### 4.2. Ценностное предложение

**Для технолога:**  
«ИКТК автоматически подбирает оборудование, проверяет реализуемость ТП и предлагает решения при дефиците — вы экономите время и избегаете ошибок».

**Для руководителя:**  
«ИКТК сокращает время ТПП на 30 %, снижает ошибки на 40 % и даёт полную картину загрузки оборудования».

**Для предприятия:**  
«ИКТК — отечественное решение с открытой архитектурой, интегрируется с любыми CAD/CAM и поддерживает импортозамещение».

### 4.3. SWOT-анализ

| Сильные стороны (S) | Слабые стороны (W) |
|---|---|
| Оркестрация, gap-анализ, рекомендации | Новый продукт на рынке |
| Импортозамещение | Меньше база пользователей |
| Открытая архитектура | Зависимость от CAD-интеграций |
| Сквозной аудит, версионность | Требует обучения |

| Возможности (O) | Угрозы (T) |
|---|---|
| Импортозамещение | Конкуренция с АСКОН, Топ Системы |
| Цифровизация производства | Экономическая нестабильность |
| ОПК, крупные предприятия | Уход или возврат западных вендоров |

## 6. Тренды рынка

### 6.1. Технологические тренды

1. **Цифровые двойники** — виртуальное моделирование производства.
2. **AI/ML в ТПП** — предиктивная аналитика, оптимизация ТП.
3. **Облачные PLM/CAPP** — SaaS-модель, снижение стоимости владения.
4. **Low-code/No-code** — настройка ТП без программирования.
5. **Industry 4.0** — интеграция с MES/ERP, IoT.
6. **Кибербезопасность** — защита КТД, mTLS, аудит.
7. **Open Source** — рост open source решений в CAD/CAM.

### 6.2. Рыночные тренды

1. **Импортозамещение** — приоритет отечественных решений.
2. **Консолидация** — слияния вендоров CAD/CAM/PLM.
3. **SaaS-модель** — переход от perpetual-лицензий к подписке.
4. **Кастомизация** — решения под конкретную отрасль.
5. **Интеграция** — единый контур CAD/CAM/CAPP/PLM/MES.

### 6.3. Регуляторные тренды

1. **Требования ОПК** — изолированные контуры, безопасность.
2. **ГОСТ и ЕСКД** — стандарты оформления документации.
3. **Реестр отечественного ПО** — приоритет для госзакупок.
4. **Санкционные ограничения** — стимул для импортозамещения.
